02 The tesseract

Four dimensions. One request.

In the film, time becomes a place you can move through. Stellar unfolds a request the same way: into steps you can watch, one dimension at a time.

  1. x

    Ask

    Type a question or drop in a file. Plain words are enough.

  2. y

    Plan

    Stellar works out the steps and picks the tools the job needs.

  3. z

    Act

    It searches, runs code in its sandbox and makes images, showing every step.

  4. t

    Deliver

    Answers, files, decks and live apps land in the chat, kept for later.

03 About Stellar

Built to go far. Kept close to home.

Some ideas need more than a reply. They need somewhere to search, to experiment, to be built and shown to someone else. Stellar puts all of that behind one conversation.

It runs on your own server with your own keys. Nobody gets in until an administrator says so, and the code it writes runs in containers that can't reach the machine they run on.

Self-hosted

Your server, your API keys, your data. Nothing on this page loads from anyone else.

Sandboxed

Code runs with dropped privileges, resource caps and its own network.

Invite-only

New accounts wait for an administrator's approval before they can chat.

Resilient

A reply keeps going if you reload the page, and any server process can pick it up.
